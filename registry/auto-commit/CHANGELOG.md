# auto-commit changelog

## 0.1.3 — 2026-08-04

Add two commit groups — `chore: update skill jobs` (`skills/*/jobs/`) and `chore: update skill config` (`skills/*/config/`) — claimed ahead of the generic Skills group so skill-owned job and config changes land under their own message instead of the catch-all one. The deprecated workspace-root `jobs/` group stays for the one-release compatibility window.

## 0.1.2 — 2026-07-28

Add a vault/ commit group (chore: update vault) for workspaces still tracking a local vault directory under version control.
